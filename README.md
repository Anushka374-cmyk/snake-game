# 🐍 Cute Snake Game

A fun, modernized twist on the classic retro Snake game! Built from scratch using vanilla HTML, CSS, and JavaScript, this version features a soft pastel aesthetic, bouncy animations, and exciting new gameplay mechanics.

## ✨ Features
* **Grid-Based Engine:** Smooth, responsive movement built with an HTML/CSS grid.
* **Portal Walls:** No more dying at the edge of the screen! The snake wraps around to the other side seamlessly.
* **Speed Ramp-Up:** The game gets progressively faster—and more frantic—the more you eat.
* **Golden Food:** Keep an eye out for the rare ⭐! It gives 50 bonus points but disappears quickly.
* **Dynamic Obstacles:** Once you score 50 points, rocks will start spawning on the board. Watch out!
* **Juicy Polish:** Features cute emoji graphics, a screen-shake effect on Game Over, sound effects, and looping lo-fi background music.

## 🎮 How to Play
1. Click the **Start** button on the main menu.
2. Use the **Arrow Keys** (⬆️ ⬇️ ⬅️ ➡️) on your keyboard to guide the snake.
3. Eat the strawberries (🍓) to grow longer and gain 10 points.
4. Catch the golden stars (⭐) before they vanish for 50 bonus points.
5. **Avoid** biting your own tail and crashing into the dark obstacles!

## 💻 Running Locally
If you want to download and run the code on your own computer:
1. Clone this repository or download the ZIP file.
2. Extract the files into a single folder.
3. Open `index.html` in any modern web browser (Chrome, Firefox, Safari, Edge).
4. Click anywhere on the page to ensure the browser allows audio to play, then click Start!

## 🛠️ Technologies Used
* **HTML5:** Game structure and audio integration.
* **CSS3:** Custom styling, soft UI, CSS Grid, and keyframe animations (screen shake).
* **JavaScript:** Game loop logic, collision detection, object spawning, and DOM manipulation.
